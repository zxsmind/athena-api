# ADR 0007 — Research quality claims require evaluation evidence

**Status:** Adopted as release policy; v1 evaluation coverage is incomplete.

## Decision

Report quality, source support, citation integrity, latency, request usage, and cost separately. A profile is not called more accurate unless a fixed query suite measures that claim. Deterministic citation/source checks must run before an LLM judge can award faithfulness.

## Consequences

The project avoids turning a pleasant demo into an unsupported accuracy promise. The v1 route and citation finalizer still need dedicated contract coverage and live provider evidence before production claims.
